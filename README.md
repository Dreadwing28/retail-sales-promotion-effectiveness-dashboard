# Retail Sales Promotion Effectiveness Dashboard

## Project overview
This project is an end to end retail analytics solution focused on measuring how promotions and discounts affect sales, margin, and inventory performance across products, stores, and channels.

## Business goal
The goal is to help business users understand whether promotions create profitable uplift or only increase revenue by sacrificing margin.

## Core business questions
1. How do sales trend by product, category, store, and channel over time
2. Which promotions drive the largest uplift in revenue and margin
3. Where is margin being lost because of excessive discounting
4. How does inventory availability affect promotion performance

## Project stack
1. SQL Server for staging and warehouse tables
2. SQL scripts for schema and transformations
3. Python for data quality checks
4. Power BI for dashboards
5. Optional SSIS and SSRS in later phases
